## Что появилось в коде

**`src/simorph/core/`** — весь слой не зависит от Qt, поэтому работает headless в CI:

| Модуль | Содержание |
|---|---|
| `schema_version.py` | сравнение версий по числам (`1.10 > 1.9`), текущая `1.0`, отказ на будущих |
| `models/` | pydantic-модели семи разделов, `extra="forbid"`, `schema_version` в каждом |
| `canonical.py` | канонизация: сортировка ключей, без пробелов, время в UTC до секунды, sha256 |
| `migrations.py` | реестр шагов `vN → vN+1`, цепочка, идемпотентность |
| `repository.py` | UTF-8 + `\n`, `.tmp` → `fsync` → `.bak` → замена |
| `locking.py` | `.lock` с pid/хостом/пользователем, обнаружение устаревших блокировок |
| `validation.py` | схема + связность, проверка циклов миссии и конвейера |
| `factory.py` | валидный проект «из коробки» |
| `settings.py` (уровнем выше) | `QSettings` с ленивым импортом Qt |

**CLI**: `simorph project new | validate | migrate | hash`, все с `--json`, коды 0/1/2; ошибки данных печатают путь к полю.
